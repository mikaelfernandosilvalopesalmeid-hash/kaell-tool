Política de Privacidade

Última atualização: 28 de setembro de 2026.

Dados coletados

Esta versão do site é estática e não possui conta de usuário, formulário de cadastro ou banco de dados próprio. O PromoNexus não solicita nome, senha, CPF ou dados de pagamento neste site.

Hospedagem

O site poderá ser hospedado no GitHub Pages. O provedor de hospedagem pode processar dados técnicos necessários para disponibilizar o serviço, como endereço IP e registros de acesso, conforme suas próprias políticas.

Links externos e afiliados

O site pode conter links para lojas e serviços de terceiros. Quando um link for de afiliado, ele será identificado quando aplicável. Ao acessar um site externo, passam a valer os termos e políticas desse terceiro.

Cookies

O PromoNexus não instala cookies próprios nesta versão estática. Serviços externos eventualmente incorporados no futuro poderão ter políticas próprias, e esta política será atualizada se isso ocorrer.

Alterações

Esta política pode ser atualizada conforme o projeto evoluir. A data exibida no início desta página indica a versão vigente.
